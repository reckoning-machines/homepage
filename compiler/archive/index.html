Earlier frontier pilot on synthetic filings

At context limits of 600 and 900 tokens, standalone cc and task-aware Graph RAG each produced four correct, fully supported answers out of six under the scoring rules set before the run. cc used fewer tokens at both limits.

At 1,200, Graph RAG plus cc scored six, Graph RAG five and standalone cc four. Crediting four disputed replies brings Graph RAG level with the combined system at six, using 1,317 fewer tokens across the six questions. This pilot preceded the real-bank benchmark.

Claude Sonnet 5.5 answered once per configuration. Independent review reproduced all 54 recorded results and all nine plotted points. Reasoning Yield counts correct, fully supported answers per million measured input and output tokens.

Under the frozen rules, cc delivered 715 supported answers per million tokens at the 600-token limit and Graph RAG delivered 570. At the 900-token limit, the corresponding yields were 543 and 510.

The four disputed replies turn on two scoring rules. Three Graph RAG replies put the unit of a correctly cited expense in parentheses. One cc reply calculated the difference between two cited estimates and supplied both sources where the scorer expected one.

Standalone cc lacked the management passage needed to explain a change in deposit costs, and it refused tasks when required inputs would not fit. Across all 54 replies, the scorer recorded no adoption of a known-wrong value from another period.

Verified privately, shown in an evaluation

  • The same inputs give the same bytes in two independent replays of each state.
  • The library calls no model and opens no network connection.
  • Adding a source outside the reader's access scope leaves the downloadable exhibit unchanged.
  • The compiler carries source text as data in its rendering.

The library runs in your environment. Source and packs are provided under agreement. This exhibit uses synthetic data and processes nothing you supply.

Source preparation

The private Python library accepts typed records, declared tables and passages that state a measure with its unit. You prepare the sources and declare their issuers, dates, access permissions and authority.
